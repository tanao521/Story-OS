# Roadmap

This roadmap describes public project directions, not internal approval or
release procedures. Items may change as implementation and community feedback
develop. “Planned” and “under evaluation” do not mean that a capability is
currently available.

## Current Foundation

- **v0.1 core workflow** — project setup, story assets, chapter planning,
  drafting, revision, review, and controlled commit workflows.
- **v0.2 memory system** — structured local project state, summaries, context
  construction, memory health checks, and optional vector indexing.
- **v0.3 AI collaboration improvements** — configurable model providers,
  fallback behavior, explicit human review, and traceable workflow evidence.
- **Current Web workflow** — local FastAPI UI for project setup, workflow
  operations, status, quality, review, and memory-oriented tools.

## Near-Term Priorities

- Make installation, configuration, and provider boundaries easier to
  understand.
- Improve contributor documentation, examples, and focused regression tests.
- Clarify the lifecycle of drafts, revisions, manual versions, review, and
  formal commits.
- Improve observability and recovery documentation for long-running workflows.
- Continue evaluating cross-chapter continuity and production-map views.

## Later Exploration

- More portable provider adapters and clearer capability negotiation.
- Reproducible evaluation fixtures for long-context and continuity workflows.
- Additional branch and timeline workflows, subject to stable data-boundary
  and review semantics.
- Better tooling for rebuilding and validating long-term memory indexes.

These areas are exploratory and are not commitments to a hosted service,
commercial platform, plugin marketplace, or general-purpose agent framework.

## Explicitly Out of Scope for Now

- One-click generation of a complete novel.
- Silent autonomous promotion of AI output into authoritative project content.
- A general multi-agent orchestration platform.
- Required cloud hosting or a mandatory provider subscription.
- Claims of production readiness across all operating systems, models, or
  deployment modes.
